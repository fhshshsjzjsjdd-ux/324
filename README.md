# Relay — лендинг LLM-шлюза

Одностраничный лендинг в духе минималистичных дизайнерских портфолио: крупный serif-логотип, спокойный гротеск, лента возможностей с пастельными «скриншотами» продукта и тихая навигация справа.

Стек: Next.js 16 (App Router), React 19, Tailwind CSS 4, TypeScript.

## Запуск

```bash
npm ci
npm run dev          # http://localhost:3000

npm run build        # продакшен-сборка (страница целиком статическая)
npm start
```

## Что где

| Путь | Что внутри |
| --- | --- |
| `content/site.ts` | название, домены, ссылки, все тексты, тарифы и FAQ |
| `content/models.ts` | витрина каталога моделей (пример данных) |
| `content/snippets.ts` | примеры кода для блока «Одна строка кода» |
| `components/shots/` | «скриншоты» продукта, свёрстанные в HTML/SVG |
| `app/globals.css` | цвета подложек, типографика, масштабирование скриншотов, подсветка кода |

Название **Relay**, домены `*.relay.example`, цены, тарифы и цифры — плейсхолдеры. Перед публикацией замените их в `content/`.

## Шрифты

Подключены через `next/font` и раздаются вместе с сайтом:

- **Fraunces** — логотип и крупные цифры (кириллицы в шрифте нет, поэтому он используется только для латиницы и чисел);
- **Inter** — основной текст, с кириллицей;
- **JetBrains Mono** — код.

## Как устроены скриншоты

Иллюстрации внутри `.shot-stage` масштабируются от ширины блока (container query units), как обычные картинки: Tailwind-утилиты `p-4`, `text-xs`, `rounded-xl` внутри сцены считаются от её ширины. Интерактивные блоки — примеры кода и каталог моделей — остаются «живыми» и читаемыми на любом экране.
